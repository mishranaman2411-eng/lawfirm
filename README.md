## Overview

A modern, cinematic web experience for **Malik & Associates**, designed around a scroll-driven architectural ascent of the Punjab & Haryana High Court. The website delivers an editorial, high-trust law firm presentation with seamless GSAP scroll storytelling, interactive lawyer profiles, expandable practice disciplines, and verified matter intake.

### Storytelling Architecture & Flow
1. **Hero Stage (`#hero-experience`)**: Edge-to-edge canvas scrub across 190 high-fidelity WebP frames with transparent architectural knockout typography (`MALIK & ASSOCIATES`) gliding over the courthouse facade. Full-bleed atmospheric video coverage on mobile viewports without cropping the architecture.
2. **Our Advocates (`#advocates`)**: Leadership hierarchy spotlighting Founding & Managing Partner Adv. Sapna Malik (full-width featured card) followed by associate counsel. Includes 3D card tilt, grayscale-to-color portrait reveal, specialty badges, and inline expandable dossier drawers.
3. **Practice Areas (`#practice-areas`)**: Five core disciplines (Commercial Litigation, Commercial Arbitration, Real Estate & HARERA, Insolvency & NCLT, Constitutional Litigation) with line-by-line clip mask reveals and expandable practice scope briefs.
4. **Firm Statistics (`#firm-statistics`)**: Verified achievement metrics (20+ Years Practice, 2 Primary Chambers, High Court & Supreme Court Benches, Partner Oversight).
5. **Litigation Doctrine (`#approach`)**: Editorial doctrine pillars detailing Evidentiary Precision, Focused Advocacy, and Commercial Judgment.
6. **Consultation & Chambers (`#consultation`)**: Chamber coordinates in New Delhi and Gurugram, alongside a confidential matter appointment form with verified conflict clearance protocol.

## Interactive Features & UX

- **Full-Screen Mobile Header**: Dual-layer atmospheric video canvas rendering on mobile (`100dvh`) with silky bilinear GPU upscaling and 100% uncropped courthouse architectural framing.
- **Mobile Navigation Drawer**: Accessible slide-out navigation menu for mobile devices with smooth backdrop blur, keyboard ESC dismissal, and automatic scroll-to-target.
- **ScrollSpy Navigation**: Real-time section tracking in both desktop header and mobile drawer with burnished gold active indicators.
- **3D Interactive Card Tilt**: Subtle, restrained 3D card tilt with specular glare lighting on hover for advocate profile cards.
- **Conflict Clearance Protocol**: Client-side telephone/email validation with simulated Chambers Registry reference receipt generation (`#MA-2026-XXXX`).
- **Floating Back-to-Top**: Quick return-to-top button appearing after scrolling past the hero sequence.
- **Structured Data**: Schema.org `LegalService` JSON-LD metadata for search engines and rich preview cards (Open Graph / Twitter).

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
Generates the optimized production bundle in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
