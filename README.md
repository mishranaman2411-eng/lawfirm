## Overview

A modern, cinematic web experience for **Malik & Associates**, designed around a scroll-driven architectural ascent of Le Corbusier’s iconic Punjab & Haryana High Court.

### Key Architectural Highlights
- **Scroll-Synchronized Video Canvas**: 190 progressive high-fidelity WebP frames scrubbed seamlessly with GSAP ScrollTrigger.
- **Transparent Architectural Knockout Typography**: The firm name (`MALIK & ASSOCIATES`) features transparent letterforms contoured with hairline architectural strokes, allowing the rising courthouse colonnade and billowing clouds to remain visible directly through the typography.
- **Precise Alignment**: Horizontally and vertically locked to the architectural center of the courthouse facade.
- **Cinematic Downward Glide**: As the user scrolls, the firm name glides slowly downward across the building facade with a subtle scale increase for 3D depth, dissolving smoothly into the Overview section.
- **Responsive Layout**: Fluidly adapts across desktop and mobile devices.
- **Editorial Sections**: Overview band, Firm Doctrine, Expandable Practice Catalogue, Espresso Doctrine Pillars, Counsel Profiles, and Chambers Consultation Booking.

## Tech Stack
- **Framework**: Vite + Vanilla Modern JS (ES Modules)
- **Animation**: GSAP + ScrollTrigger
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Typography**: Plus Jakarta Sans, JetBrains Mono

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized bundle will be generated in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
